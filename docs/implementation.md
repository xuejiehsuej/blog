# 素屿札记 · 第一版

## 已确认的第二轮 · 动态档案

用户确认鼠标景深、滚动错位推进、卡片展开与页面切换；雨夜窗景，结合胶片与报纸；刊名中的单字连续点五次触发暗号窗口。无需额外设计批准。

实现：entrance.js 封装计数（相邻点击超过 1.2 秒重置）；atmosphere.js 管理鼠标/滚动与可见性；atmosphere.css 与 rain-window.svg 承担独立动态视觉。正文保持不透明纸张底，手机停用指针景深，减少动态偏好时停用连续动画，后台暂停循环。删除旧页脚入口及线索，按钮只有键盘 focus-visible 状态，鼠标触摸不高光。

验证：五击/间隔重置/点击其他位置重置、移动端五次 tap、无选区及点击高光；视差变换实际变化、滚动进入、卡片展开、持续动画、减少动态模式；回归原有阅读与解密测试。

第二轮已完成：雨夜背景、落雨/灯光、报纸照片视差、循环胶片、滚动显现、桌面卡片展开与路由入场。已移除旧页脚入口及明示口令线索，刊名「屿」字五击触发。保留键盘焦点可见性，但鼠标/触摸无背景高光和选中文字。

最新证据：docs/qa/atmosphere/report.json 与对应日/夜、桌面/手机截图。1440px 与 390px（含真实 touch 模拟）均验证无横向溢出、连续点击与间隔/外部点击重置、鼠标视差、实际雨滴运动、减少动态偏好关闭动画、搜索不触发整页动画。原有 browser.mjs 阅读/筛选/解密/锁定测试及 edge-cases.mjs 回归通过。复核发现搜索入场动画问题，已拆分路由入场与列表观察。仍只提供本地预览，未部署远端。

已确认：公开评论与随笔、隐藏手记、共享口令、静态部署。视觉借鉴重返未来 1999 的复古报刊和档案气质，不使用游戏素材。暖白、酒红、衬线标题；深色模式；手机完整适配。

实现顺序：
1. 建立加密往返与错误口令测试，验证失败后实现 Web Crypto AES-GCM + PBKDF2。
2. 内容与界面分离：data/posts.json、assets/app.js、assets/style.css。公开列表支持分类、搜索；hash 文章链接支持刷新、返回。
3. 首页原创 SVG 静物插画；阅读视图、目录、日夜切换；页脚标点打开原生 dialog，解密后显示手记、支持锁定。
4. scripts/build.mjs 输出 dist，读取公开 GitHub Issue（分页、作者限制、失败终止），生成 RSS。scripts/seal.mjs 从外部文件加密私人 JSON。
5. 浏览器验证桌面/手机、搜索空态、阅读返回、错误口令/正确口令、重新锁定、主题持久化及无横向溢出。保存截图。

内容是演示稿，不代表作者真实经历和立场。演示口令「雨停之后」。正式部署只上传 dist，私人原文不进入公开仓库。当前轮不发布远端。
